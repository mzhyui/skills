# PowerPoint editability

Illustrative workflow, 7 × 3.4 inches. Font: DejaVu Sans.

| Selection Pane name | Editing behavior |
| --- | --- |
| `panel-*` | Native rounded rectangles; resize/recolor |
| `title-*`, `output-*`, `*-label`, `figure-title` | Native editable text |
| `node-*` | Native shapes with editable text |
| `icon-*` | Groups of native rectangles and lines; ungroup to edit parts |
| `specify-to-compose`, `compose-to-validate` | Connectors attached to nodes |
| `revise-layout-manual-route` | Native freeform; manually reroute after moving panels |

No pictures or outlined text are used. Programmatic attachment metadata does not establish interactive behavior in every presentation editor.

This generator is the initial source. Preserve subsequent manual PPTX edits before regeneration; SVG/PDF companions are not updated automatically.
